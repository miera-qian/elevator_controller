# Elevator Scheduling Algorithm - SCAN 调度算法

基于 SCAN 算法（电梯寻道算法）的智能电梯调度系统，通过多种优化策略最小化乘客等待时间。

## 算法核心思想

### 1. 主方向服务（Directional Service）
- 每部电梯维持一个主服务方向（上行/下行/空闲）
- 沿主方向运行，直到该方向上所有请求（接客+送客）完成
- 类似磁盘调度中的 SCAN 算法，减少无效往返

### 2. 端点掉头（End-Point Reversal）
- 当前方向无任务时，自动掉头服务反方向请求
- 避免空载往返，提高电梯利用率
- 确保所有楼层请求最终都会被响应

### 3. 智能任务分配（Smart Task Assignment）
采用多因素评分机制为空闲电梯选择最优目标：

- **热力图评分**：优先派遣电梯到等待人数多的楼层（100分/人）
- **距离优化**：考虑电梯当前位置，减少空驶距离（-10分/层）
- **场景自适应**：在第 50 个 tick 自动识别流量模式
  - 上行高峰：优先使用底层（0-2层）的空闲电梯 (+25分)
  - 下行高峰：优先使用高层的空闲电梯 (+25分)
  - 混合场景：均衡分配
- **空载加成**：完全空载的电梯优先派遣 (+15分)
- **顺路接客**：工作中的电梯可在途中接载同向乘客

### 4. 负载管理（Load Management）
- 电梯负载超过 **80% 阈值**时，跳过接客请求
- 直接送客到目的地，避免满载电梯频繁停靠
- 防止过载导致的延误和服务质量下降

### 5. 竞态避免（Race Condition Prevention）
- 多电梯同时到达同一楼层时，通过 **ID 仲裁机制**避免重复响应
- ID 最小的电梯负责接客，其他电梯进入空闲状态
- 防止空载电梯无效运行，提高系统效率

## 快速启动

### 方式一：Web 可视化界面（推荐）

```bash
./start.sh
```

- 🎬 实时电梯位置可视化

- ⏯️  交互式控制（暂停/继续/速度调节）
- 📊 实时性能指标统计

**适用场景：**

- 自动化评估流程

## 依赖环境

- **Python 3.12+**
- 依赖包通过 `uv` 自动管理（start.sh 会自动安装 uv 和依赖）
- 基于 `elevator-saga` 框架（v0.0.10）

## 性能指标

模拟器会实时统计以下指标：

- **平均等待时间**：所有乘客的平均楼层等待时长（秒）
- **P95 等待时间**：95% 乘客的等待时长上限（秒）
- **完成乘客数**：成功送达目的地的乘客总数
- **等待/在梯人数**：实时统计等待和乘坐中的乘客数量

## 算法优势

与传统电梯调度算法相比，本实现具有以下优势：

1. **自适应性强**：自动识别流量模式，动态调整策略
2. **公平性好**：SCAN 策略保证所有楼层的请求都能被响应
3. **效率高**：热力图评分和负载管理提高电梯利用率
4. **鲁棒性强**：竞态避免机制防止多电梯冲突
